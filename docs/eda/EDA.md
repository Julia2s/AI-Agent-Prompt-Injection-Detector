## Распределение меток

| Split      | Benign (0) | Injection (1) | Доля injection |
| ---------- | ---------- | ------------- | -------------- |
| Train      | 274        | 162           | 37.2 %         |
| Validation | 69         | 41            | 37.3 %         |
| Test       | 56         | 60            | 51.7 %         |

Классы несбалансированы: в train/validation ~63 % benign, в test — почти баланс.
Поэтому **accuracy не информативна**: константный классификатор даст те же ~63 % на train/val, но 51.7 % на test.
**Основная метрика — F1 для класса 1 (injection).**
Дополнительные метрики: precision, recall, PR-AUC, confusion matrix.

- Высокий recall → меньше пропущенных атак.
- Высокий precision → меньше ложных блокировок легитимных запросов.

Сдвиг баланса между train/val и test влияет на accuracy, precision и PR-AUC. Гиперпараметры подбираются по validation; интерпретация метрик на test должна учитывать более высокую долю injections.

## Ограничения

- Набор небольшой (662 примера), не гарантирует устойчивость к новым видам атак или другим языкам.
- Поле языка отсутствует — точные языковые доли не заявляются.
- Фразы анализируются как текст, никогда не выполняются.
- Лицензия источника противоречива (Apache-2.0 vs CC-BY-4.0) — оригинальная карточка сохранена в `data/raw`.
